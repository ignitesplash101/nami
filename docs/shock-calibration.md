## What this measures

The real pipeline runs in backdated, leave-one-out mode: each event gets an ex-ante prompt and an as-of date on the trading day before it began, so the event itself can never be one of the analogs the model selects. Each run's shocks are scored through the same vintage betas as variants that differ only in who sets the numbers.

| variant | meaning |
|---|---|
| L0_headline | production headline as returned (incl. single-name shocks) |
| L0 | model shocks, unnamed factors at 0 (factor-only, scoring betas) |
| L1 | model's named factors as anchors, completed by covariance |
| L2 | same anchors at analog-median magnitudes, completed |
| L3 | mean realized vector of the selected analogs |
| full_replay | the event's own realized factor vector (engine upper bound) |

Honest read: the model knows how every one of these episodes ended (its knowledge is not vintage-controlled), which favors the model-driven variants. A result where history matches or beats the model is therefore robust; the reverse is not. Books are today's frozen weights; the model-driven variants are averaged over a pair's repeated samples.

The targets are hard by construction. Several registry windows are anchored on ex-post peaks and troughs (`covid-crash-2020` runs exactly peak to trough), and some include the reversal that ended the episode (`us-tariffs-2025` ends after the tariff pause and rebound). No ex-ante scenario could be expected to hit those numbers, so the absolute error level overstates what a scenario tool could achieve. The comparison BETWEEN variants is fair: every variant faces the same targets through the same betas.

# Completion study — coherent scenarios and an explainable basis

> Generated by `uv run python scripts/run_completion_study.py`. Do not hand-edit.
> No language model is involved anywhere in this study.

## What this measures

Production fills every factor a scenario does not name with **exactly zero**. This study asks how much of a book's realized outcome each alternative recovers when the scenario states only a few moves correctly. For each (historical event × sample book) pair, the anchors are the event's own realized moves for the anchor set, betas are estimated at the event's vintage (no look-ahead), and the modeled factor P&L is compared with the book's realized buy-and-hold USD return.

Completion uses the conditional expectation of the unanchored factors given the anchors, `s_u = Σ_ua Σ_aa⁻¹ a`, with Σ the vintage weekly covariance after Ledoit–Wolf shrinkage of the correlations. The relative basis replaces each non-market equity factor `k` by `r_k − b_k·r_SPY`.

| variant | meaning |
|---|---|
| V0 | raw basis, unanchored = 0 (production today) |
| V1 | raw basis, conditional completion |
| V2 | relative basis, unanchored relative = 0 |
| V3 | relative basis, conditional completion |
| V4 | relative basis, completion with stress-week covariance |
| V5 | relative basis, completion, yield-change / log units |

| anchor set | anchors |
|---|---|
| `market` | SPY only |
| `market_macro` | SPY + the seven macro factors |
| `market_top2` | SPY + the two most extreme other moves |
| `market_top4` | SPY + the four most extreme other moves |

Honest read: anchors are realized moves, so this is an upper bound on what a perfectly specified scenario could deliver, not the LLM's skill. Books are today's frozen weights replayed onto history (survivorship and drift), and the modeled side is factor-only. `top2`/`top4` pick the most extreme realized moves, which uses hindsight to mimic a scenario that names its salient drivers.
